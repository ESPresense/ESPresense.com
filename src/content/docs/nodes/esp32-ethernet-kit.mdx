:::caution[New page]
Pin data comes from the vendor's docs and schematics and hasn't been checked on hardware yet. The **Templates** page and the `eth` setting in templates need firmware with [ESPresense#2531](https://github.com/ESPresense/ESPresense/pull/2531). On older firmware, pick the Ethernet Type on the Network page and copy the pins into the Hardware page by hand. This kit also needs [ESPresense#2537](https://github.com/ESPresense/ESPresense/pull/2537), which corrects its PHY address; without it Ethernet doesn't start.
:::

## Notes

- The firmware calls this **KIT-VE** (`eth` 7). "VE" is the version with the ESP32-WROVER-E module.
- The FT2232H shows up as two serial ports: the first is JTAG, the second is the ESP32's serial port. Pick the second one in the browser installer.
- The PoE board is IEEE 802.3at. USB power is cut off automatically when PoE is present.
- There's no user LED; the link and activity LEDs are driven by the PHY.
- I2C is off in the template. For a sensor, any two of 32, 33, 4 and 2 work. GPIO 12–15 are free only with DIP switches 1–4 off (on routes them to JTAG). GPIO 16/17 are used by PSRAM. The plain `esp32` build defaults I2C bus 1 to GPIO 21/22, which are Ethernet pins, so Ethernet fails to start ([#2510](https://github.com/ESPresense/ESPresense/issues/2510)).
- GPIO 18, 19, 21, 22, 23, 25, 26 and 27 belong to Ethernet (RMII and MDIO/MDC). Don't put sensors on them. GPIO 0 and 5 too.
