## Notes

- **Flashing:** pry the back plate off from its notch (there are no screws) and unplug the antenna. Wire a 3.3 V USB-TTL adapter's TX, RX and GND to the header on the PCB (not VCC), then hold the **internal** button next to the USB port while plugging in micro-USB power. The outside button is not the boot button. GL.iNet has a [flash guide](https://docs.gl-inet.com/iot/en/ble_proxy/gl-s10/flash_guide).
- **Never connect USB and PoE at the same time.**
- The Ethernet Type entry is for hardware v2.1 and later (IP101 PHY). v1.0 units used a LAN8720 and aren't covered by this entry.
- The template uses the white LED for status and the side button as button 1. The power LED (GPIO 14) and BLE LED (GPIO 12) aren't configured; GPIO 12 is a strapping pin, so leave it alone.
- I2C is off in the template. If you add a sensor, the pads inside are SDA 15 and SCL 13. A light sensor works; a temperature sensor inside the case reads the board's own heat.
- The plain `esp32` build defaults I2C bus 1 to GPIO 21/22, which are Ethernet pins, so Ethernet fails to start ([#2510](https://github.com/ESPresense/ESPresense/issues/2510)). The template sets I2C explicitly; keep it that way if you edit it.
- Earlier ESPresense issues with this board are fixed: PoE link drops ([#888](https://github.com/ESPresense/ESPresense/issues/888)) and packet loss ([#1182](https://github.com/ESPresense/ESPresense/issues/1182)).
