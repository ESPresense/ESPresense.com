## Notes

- The generic `esp32s3` build defaults LED 1 to a PWM LED on GPIO 2, which this board doesn't have. Without the template the status LED stays dark.
- Plugging an I2C sensor into the GROVE port? Set `I2C_Bus_1_SDA` to 2 and `I2C_Bus_1_SCL` to 1 before importing.
- The IR emitter isn't used by ESPresense.
