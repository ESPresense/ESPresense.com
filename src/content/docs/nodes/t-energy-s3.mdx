## Notes

- **Why this board:** a battery-powered node you can carry around, for example to stand at known spots during [calibration](/configuration/settings#calibration). Charge it over USB-C and use the power switch between sessions.
- **Battery life:** ESPresense keeps WiFi and BLE scanning on, so expect roughly 90–150 mA. A 2,500–3,500 mAh 18650 gives about 17–39 hours. Estimate, not a measurement.
- Use an 18650 cell. LILYGO's board has its own charge (HX6610S) and protection (IP3005A) chips.
- **Charge reminder:** the template sets **Battery voltage pin** to GPIO 3 with a ×2 divider, so the node reports Battery (%) and Battery Voltage to Home Assistant. Add an automation to notify you below, say, 20 %.
- Install the **`esp32s3-cdc`** flavor. USB-C goes to the S3's native USB; the plain `esp32s3` build talks on the UART pins instead. If flashing fails, hold BOOT and press reset.
- There's no user LED: the red LED shows power and the other two show charging. The `esp32s3` build defaults to an LED on GPIO 2, so the template clears the LED list.
- The 4-pin connector is UART (RX, TX, 3V3, GND), not Qwiic. For I2C, use two free header pins, for example 17/18.
- GPIO 15/16 drive the 32 kHz crystal. GPIO 35–37 are used by the octal PSRAM.
