## Notes

- **Why this board:** it's a battery-powered node you can carry around, for example to stand at known spots during [calibration](/configuration/settings#calibration). Charge it over USB-C and use the power switch between sessions.
- **Battery life:** ESPresense keeps WiFi and BLE scanning on all the time, so expect roughly 90–150 mA. A 2,500–3,500 mAh 18650 gives about 17–39 hours. That's an estimate, not a measurement.
- Use an 18650 cell. LILYGO's board has its own charge (HX6610S) and protection (IP3005A) chips.
- **Charge reminder:** the template sets **Battery voltage pin** to GPIO 3 with a ×2 divider, so the node reports a Battery (%) and a Battery Voltage sensor to Home Assistant. Add an automation that notifies you when Battery drops below, say, 20 %.
- Install the **`esp32s3-cdc`** flavor. USB-C goes to the S3's native USB, and the standard `esp32s3` build talks on the UART pins instead. If flashing fails, hold BOOT and press reset.
- There's no user LED: the red LED shows power and the other two show charging. The `esp32s3` build defaults LED 1 to GPIO 2 and I2C to GPIO 21/22, so the template turns both off.
- The 4-pin connector is UART (RX, TX, 3V3, GND), not Qwiic. For an I2C sensor, use two free header pins, for example 17/18.
- GPIO 15/16 drive the 32 kHz crystal. GPIO 35–37 are used by the octal PSRAM.
