## Notes

- The template uses the blue LED for status. The RGB LED is only powered when GPIO 19 is driven high, and the firmware has no setting for a power-enable pin, so it stays dark.
- GPIO 9 is also the boot strapping pin: holding the button while plugging in enters download mode.
