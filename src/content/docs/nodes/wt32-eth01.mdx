## Notes

- There's no USB. Flash it with a 3.3 V USB-TTL adapter on the programming header (TXD = IO1, RXD = IO3, GND, 3V3): tie IO0 to GND, power it up, flash, then remove the IO0 link.
- Power it from **either** the 5V pin or the 3V3 pin, never both. There's no PoE; use a PoE splitter if you want one cable.
- There's no user LED or button. LED3/LED4 follow IO5/IO17 serial traffic.
- I2C is off in the template. For a sensor, SDA 33 / SCL 32 is the pair known to work alongside Ethernet. The plain `esp32` build defaults I2C bus 1 to GPIO 21/22, which are Ethernet pins, so Ethernet fails to start ([#2510](https://github.com/ESPresense/ESPresense/issues/2510)).
- GPIO 18, 19, 21, 22, 23, 25, 26 and 27 belong to Ethernet (RMII and MDIO/MDC). Don't put sensors on them. GPIO 0 and 16 too. GPIO 2 and 12 are strapping pins.
- The **WT32-ETH01 EVO** (ESP32-C3 + DM9051) is a different board and isn't supported ([#2400](https://github.com/ESPresense/ESPresense/issues/2400)).
