## Notes

- **I2C buses.** The stick has three I2C connections, one bus each, so a GROVE add-on and a HAT work together:
  - **Bus 1** is the GROVE port on GPIO 32/33, for an add-on such as the [ENV IV](/addons/m5stack-env-iv).
  - **Bus 2** is for the HAT header on GPIO 0/26. The board template leaves it off, because not every HAT uses those pins for I2C; a HAT's add-on template, e.g. the [ENV II HAT](/addons/m5stack-env-ii-hat), turns it on.
  - **Bus 3 (software)** is the internal bus on GPIO 21/22. The template puts the AXP192 power chip there (**Gauge I2C bus** Bus 3, **Gauge chip** AXP192) for battery level, voltage and charging. It also clears bus 2's pins, so a v4 default of bus 2 on 21/22 can't drive the same pins.
- **`leds` is empty on purpose.** Without it, the generic `esp32` build's default status LED on GPIO 2 drives the buzzer. The red LED on GPIO 10 (active low) can be added as a `pwm_inverted` LED; that pin is from M5Stack's docs and hasn't been checked with ESPresense.
- Both buttons have external pull-ups, so they use `floating_inverted`. Both are checked on hardware.
- The screen, IMU, RTC and IR emitter aren't used by ESPresense.
