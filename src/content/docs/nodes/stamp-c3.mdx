## Notes

- The generic `esp32c3` build defaults to a PWM LED on GPIO 2, but this board's LED is addressable. Without the template the status LED never lights.
- Install the plain **`esp32c3`** flavor. The board has a USB-to-serial chip, so it doesn't need `esp32c3-cdc`. (The Stamp C3U has native USB and does.)
- No I2C is wired on the board, and I2C is off by default.
