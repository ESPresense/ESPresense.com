## Flashing

[ESPreSwitch](/espreswitch/) converts a stock plug to ESPresense over WiFi, no disassembly needed. It installs the full ESPresense image, bootloader and partition table included, so the plug ends up on the same flash layout as any other node. It has been tested on stock firmware v2.7; newer versions are untested, so **don't accept SwitchBot firmware updates** before converting. If the OTA route is closed, you'll need serial, and the case is welded shut.

Plugs converted earlier with [SwitchbOTA](https://github.com/kendallgoto/switchbota) still have Tasmota's bootloader and partition table. ESPreSwitch moves them to ESPresense's layout over MQTT, without Bluetooth: see [Plugs already running ESPresense](https://github.com/ESPresense/ESPreSwitch#plugs-already-running-espresense).

## Notes

- **The relay is output 1.** It shows in Home Assistant as a switch named Relay, and MQTT `espresense/rooms/<room>/output_1/set` takes `ON`, `OFF` or `TOGGLE`. The button toggles it, and after a power cut it returns in its last state. The white LED follows the relay; the other shows status.
- **Power monitoring** uses the BL0937 with [digiblur's ESPHome calibration](https://digiblur.com/wiki/devices/plugs/switchbot_15_amp_w1901400/) (`voltage_divider` 1450, `current_resistor` 0.0011). Reports power, voltage, current and energy every 10 s. SEL is inverted here (`sel_inverted: true`, as in that config).
- **Always-on loads** such as a robot vacuum dock: set the output to `"power_on": "on", "input": 0`. The plug then always powers up on, and a bump of the button no longer cuts the dock. Home Assistant can still switch it, and it still reports power.
