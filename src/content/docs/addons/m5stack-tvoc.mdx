## Notes

- Plug it into the GROVE port. The [Atom S3 Lite](/nodes/atom-s3-lite) and [NanoC6](/nodes/nanoc6) board templates set GROVE as I2C bus 1. On another board, set I2C bus 1's SDA and SCL pins on the Hardware page first.
- Applying the template needs firmware v5.0.0b3 or newer ([ESPresense#2555](https://github.com/ESPresense/ESPresense/pull/2555)). Older firmware asks for a `"chip"`; set the values on the Hardware page instead.
- Publishes `tvoc` (ppb) and `co2` (ppm). The CO2 value is an estimate from the VOC reading, not a measurement; for real CO2 use an SCD4x such as the [M5Stack CO2 Unit](/addons/m5stack-co2). Both publish to `co2`, so use one or the other.
- The SGP30 needs a few minutes after power-up before its readings settle.
