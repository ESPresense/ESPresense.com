## Template

<AddonPage part="howto" />

Seeed made this board with two different chips. Use the template for yours, not both: Home Assistant would show the missing chip's sensors as unavailable.

### BMP280

<AddonPage part="template" variant="BMP280" />

Publishes `bmp280_temperature` and `bmp280_pressure`. If nothing shows up, try `"BMP280_I2c": "0x76"`.

### BMP180 (older board)

<AddonPage part="template" variant="BMP180" />

Publishes `bmp180_temperature` and `bmp180_pressure`. The BMP180 is always at 0x77.

## Notes

- Plug it into the GROVE port. The [Atom S3 Lite](/nodes/atom-s3-lite) and [NanoC6](/nodes/nanoc6) board templates set GROVE as I2C bus 1. On another board, set I2C bus 1's SDA and SCL pins on the Hardware page first.
- Applying a template needs firmware newer than v5.0.0b2 ([ESPresense#2555](https://github.com/ESPresense/ESPresense/pull/2555)). Older firmware asks for a `"chip"`; set the values on the Hardware page instead.
- Not sure which chip you have? Turn on "Debug I2C addresses" on the Hardware page, or apply one template and check the serial log: the wrong driver logs "Couldn't find a sensor".
