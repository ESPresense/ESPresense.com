## Notes

- Plug it into the GROVE port. The [Atom S3 Lite](/nodes/atom-s3-lite) and [NanoC6](/nodes/nanoc6) board templates set GROVE as I2C bus 1. On another board, set I2C bus 1's SDA and SCL pins on the Hardware page first.
- Applying the template needs firmware newer than v5.0.0b2 ([ESPresense#2555](https://github.com/ESPresense/ESPresense/pull/2555)). Older firmware asks for a `"chip"`; set the values on the Hardware page instead.
- The template is for the BMP280 version. The older board has a BMP180; for that one apply this instead:

  ```json
  {"settings": {"BMP180_I2c_Bus": 1, "BMP180_I2c": "0x77"}}
  ```

  Don't set both: Home Assistant would show the missing chip's sensors as unavailable.
- Publishes `bmp280_temperature` and `bmp280_pressure` (BMP180: `bmp180_temperature` and `bmp180_pressure`).
- If nothing shows up, try `"BMP280_I2c": "0x76"` (BMP280 only; the BMP180 is always 0x77), or turn on "Debug I2C addresses" on the Hardware page and check the serial log.
