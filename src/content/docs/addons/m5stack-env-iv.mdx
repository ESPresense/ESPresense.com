## Notes

- Plug it into the GROVE port. The [Atom S3 Lite](/nodes/atom-s3-lite) and [NanoC6](/nodes/nanoc6) board templates set GROVE as I2C bus 1. On another board, set I2C bus 1's SDA and SCL pins on the Hardware page first.
- Applying the template needs firmware v5.0.0b3 or newer ([ESPresense#2555](https://github.com/ESPresense/ESPresense/pull/2555)). Older firmware asks for a `"chip"`; set the three values on the Hardware page instead.
- The SHT40 publishes `temperature` and `humidity`; the BMP280 publishes `bmp280_temperature` and `bmp280_pressure`. The SHT40's temperature is the more accurate of the two.
- Earlier firmware needed a separate M5Stack driver for this unit ([ESPresense#2242](https://github.com/ESPresense/ESPresense/pull/2242)). The current BMP280 and SHT drivers handle it directly.
